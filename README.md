## 🪶 [LowBloat](https://lowbloat.app/pt/) · *useful software, no excess*

Independent software company. Lightweight desktop, mobile and self-hosted tools, mostly open source (AGPL-3.0).

| Product | What it does | Stack |
|---|---|---|

| [**LowQuery**](https://github.com/LowBloat/LowQuery) | Light SQL client for 7 databases with native drivers. Oracle without Oracle Client. MCP-ready | Rust · Tauri |
| [**LowMail**](https://github.com/LowBloat/LowMail) | E-mail client for your own server: desktop, Android and a Roundcube-replacement webmail. IMAP, SMTP, Sieve | Rust · Tauri · Svelte |
| [**LowLex**](https://github.com/LowBloat/LowLex) | Translation server in one binary + one SQLite file. MT and AI, i18next / PO / Android / iOS formats | Rust · SQLite |
| **LowDesk** | Helpdesk with tickets, e-mail channel, public help center and internal notes | SaaS |
| **LowArchive** · **LowProjects** | Self-hosted document archive with OCR · project & task management | *in development* |
